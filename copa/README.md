# Copa DH Simulador

App web aparte (PWA) que simula la Copa de España de Clubes de Natación, División de Honor 2026 (Can Llong, 18-20 dic).
Se publica como un sitio propio de Netlify con "Base directory" = `copa`.

- `data.js`: resultados oficiales de la Copa 2025 (DH y Primera) convertidos con `herramientas/parse.py` y `herramientas/build.py`.
- `app.js`: reglamento 2026-27, alineación automática, puntuación, probabilidades (Monte Carlo).
